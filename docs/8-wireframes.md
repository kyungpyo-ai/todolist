## 공통 레이아웃

### 공통 헤더 — 데스크톱

**설명:** 로그인한 사용자가 접근하는 모든 화면 상단에 표시되는 헤더입니다. 앱 타이틀, 메인 네비게이션, 사용자 이름, 테마 토글 버튼(v2)을 포함합니다.

```
┌──────────────────────────────────────────────────────────────────────────────┐
│  TodoList          [할일 목록]  [카테고리]  [내 정보]    박성훈님  [🌙]  [로그아웃] │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 공통 레이아웃 — 모바일

**설명:** 모바일에서는 상단 헤더를 최소화하고, 하단 탭 바로 네비게이션을 처리합니다.

```
┌──────────────────────────┐
│  TodoList       [🌙] [⋮] │  ← 상단: 앱 타이틀 + 테마 토글[v2] + 더보기 메뉴
├──────────────────────────┤
│                          │
│       (화면 컨텐츠)       │
│                          │
├──────────────────────────┤
│  [📋 할일] [🏷 카테고리]  │  ← 하단 탭 바
│  [👤 내정보] [🚪 로그아웃] │
└──────────────────────────┘
```

**주요 컴포넌트:**
- 앱 타이틀: "TodoList" (클릭 시 할일 목록으로 이동)
- 네비게이션 탭: 할일 목록 / 카테고리 / 내 정보 (현재 페이지는 활성 강조)
- 사용자 이름 표시: "홍길동님"
- 테마 토글 버튼: 라이트/다크 모드 전환 [v2]
- 로그아웃 버튼

## 3. 할일 목록 화면 (SCR-03)

**화면 설명:** 로그인한 사용자의 할일 목록을 카드 형태로 표시하는 메인 화면입니다. UC-09에 해당하며 카테고리·상태·기한 초과 필터를 지원합니다. 할일이 없을 때는 빈 상태 안내 메시지를 표시합니다.

**와이어프레임:**

```
┌──────────────────────────────────────────────────────────────────────────────┐
│  TodoList       [할일 목록]  [카테고리]  [내 정보]    박성훈님  [🌙]  [로그아웃] │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  할일 목록                                          [+ 새 할일 등록]          │
│                                                                              │
│  ┌─────────────────── 필터 영역 ─────────────────────────────────────────┐   │
│  │ 카테고리: [전체 ▼]    상태: [전체 ▼]    [기한 초과 미완료]             │   │
│  └───────────────────────────────────────────────────────────────────────┘   │
│                                                                              │
│  ┌───────────────────────────────────────────────────────────────────────┐   │
│  │ [기본] 알고리즘 기말 대비                      [기한초과] 미시작         │   │
│  │ 2026-05-27 ~ 2026-06-01                                               │   │
│  │                                                          [수정] [삭제] │   │
│  └───────────────────────────────────────────────────────────────────────┘   │
│                                                                              │
│  ┌───────────────────────────────────────────────────────────────────────┐   │
│  │ [업무] 주간 보고서 작성                                      진행중    │   │
│  │ 2026-05-26 ~ 2026-05-28                                               │   │
│  │                                                          [수정] [삭제] │   │
│  └───────────────────────────────────────────────────────────────────────┘   │
│                                                                              │
│  ┌───────────────────────────────────────────────────────────────────────┐   │
│  │ [개인] 병원 예약                                               완료    │   │
│  │ 2026-05-20 ~ 2026-05-20                                               │   │
│  │                                                          [수정] [삭제] │   │
│  └───────────────────────────────────────────────────────────────────────┘   │
│                                                                              │
│  ┌───────────────────────────── 빈 상태 안내 (항목 없을 때만 표시) ───────┐   │
│  │                                                                       │   │
│  │              아직 등록된 할일이 없습니다.                              │   │
│  │              [+ 새 할일 등록하기]                                      │   │
│  │                                                                       │   │
│  └───────────────────────────────────────────────────────────────────────┘   │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘
```

**할일 카드 상세 레이아웃:**

```
┌───────────────────────────────────────────────────────────────────────────┐
│ [카테고리명]  할일 제목 (최대 200자)                [기한초과] 상태뱃지     │
│ YYYY-MM-DD ~ YYYY-MM-DD                                                   │
│ (설명이 있을 경우) 상세 내용 미리보기 텍스트 한 줄...                       │
│                                                             [수정] [삭제] │
└───────────────────────────────────────────────────────────────────────────┘
```

**상태 뱃지 표시 규칙:**
```
미시작    → 회색 배경   "미시작"
진행중    → 파란 배경   "진행중"
완료      → 초록 배경   "완료"
기한초과  → 빨간 배경   "기한초과" (endDate < 오늘 AND status != DONE)
```

**필터 드롭다운 옵션:**
```
카테고리 드롭다운: [전체] [기본] [업무] [개인] ... (사용자 카테고리 목록)
상태 드롭다운:    [전체] [미시작] [진행중] [완료]
기한 초과 버튼:  토글 버튼 (선택 시 강조)
```

**주요 컴포넌트:**
- 페이지 타이틀 및 새 할일 등록 버튼
- 필터 영역: 카테고리 드롭다운, 상태 드롭다운, 기한 초과 미완료 토글 버튼
- 할일 카드 목록: 카테고리명, 제목, 날짜 범위, 상태 뱃지, 기한 초과 뱃지, 수정/삭제 버튼
- 빈 상태 안내 메시지 (할일 없을 때)

**화면 설명:** 로그인한 사용자가 이름·비밀번호를 수정하고, 언어·테마 설정을 변경하며, 회원 탈퇴를 진행하는 화면입니다. UC-03(내 정보 수정)·UC-04(회원 탈퇴)·UC-12(테마 변경, v2)·UC-13(언어 변경, v2)에 해당합니다.

**회원 탈퇴 확인 다이얼로그 (UC-04):**

```
              ┌──────────────────────────────────────────┐
              │              회원 탈퇴                   │
              │                                          │
              │  탈퇴 시 모든 할일과 카테고리가          │
              │  영구적으로 삭제됩니다. 계속하려면       │
              │  현재 비밀번호를 입력해주세요.           │
              │                                          │
              │  비밀번호                                │
              │  ┌──────────────────────────────────┐   │

              │  └──────────────────────────────────┘   │

              │    (불일치 시 표시)                      │
              │                                          │
              │              [취소]  [탈퇴 확인]        │
              └──────────────────────────────────────────┘
```

**주요 컴포넌트:**
- 기본 정보 섹션
  - 이메일 표시 (읽기 전용, 변경 불가)
  - 이름 입력 필드 (편집 가능)
- 비밀번호 변경 섹션
  - 현재 비밀번호 입력 필드
  - 새 비밀번호 입력 필드
    - 인라인 오류: "비밀번호 조건을 확인해주세요"
  - 새 비밀번호 확인 입력 필드
    - 인라인 오류: "새 비밀번호가 일치하지 않습니다" (실시간 표시)
- 저장 버튼: 이름·비밀번호 모두 미변경 상태에서는 비활성화
- 환경 설정 섹션 [v2]
  - 언어 드롭다운: 한국어(ko) / 영어(en), 선택 즉시 UI 언어 전환 및 서버 저장 (UC-13)
  - 테마 드롭다운: 라이트 모드 / 다크 모드, 선택 즉시 적용 및 서버 저장 (UC-12)
- 위험 구역 섹션
  - 탈퇴 안내 문구
  - 회원 탈퇴 버튼 (강조 색상)
- 회원 탈퇴 확인 다이얼로그: 비밀번호 재확인 포함 (UC-04)

**UX 흐름:**
- 이름 또는 비밀번호 변경 후 저장 버튼 클릭 → 서버 저장 → 성공 메시지 표시
- 이름·비밀번호 모두 미변경 시 저장 버튼 비활성화
- 새 비밀번호/확인 불일치 시 즉시 인라인 오류 표시, 저장 차단
- 언어 드롭다운 변경 → 즉시 전체 UI 언어 전환 + 서버 저장 [v2]
- 테마 드롭다운 변경 → 즉시 전체 UI 테마 전환 + 서버 저장 [v2]
- 회원 탈퇴 버튼 클릭 → 비밀번호 확인 다이얼로그 표시
- 비밀번호 입력 후 탈퇴 확인 → 계정·할일·카테고리 전체 삭제 → 로그인 화면(SCR-01)으로 이동

## 화면 흐름 요약

```
[비인증]
  SCR-01 로그인 화면
    │ 회원가입 링크
    ▼
  SCR-02 회원가입 화면
    │ 가입 완료
    ▼
  SCR-01 로그인 화면
    │ 로그인 성공
    ▼
[인증 후 — 공통 헤더 표시]
  SCR-03 할일 목록 화면 ◀──────────────────────────────────────┐
    │ + 새 할일 등록 버튼                                       │
    ├──▶ SCR-04 할일 등록 폼 ──────── 저장/취소 ───────────────┤
    │                                                           │
    │ 수정 버튼 클릭                                            │
    ├──▶ SCR-04 할일 수정 폼 ──────── 저장/취소 ───────────────┘
    │
    │ 네비게이션 — 카테고리
    ├──▶ SCR-05 카테고리 관리 화면
    │
    │ 네비게이션 — 내 정보
    └──▶ SCR-06 내 정보 화면
              │ 회원 탈퇴 완료
              ▼
           SCR-01 로그인 화면
```
